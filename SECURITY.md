# Security Policy 🔒

## Supported Versions

We actively provide security updates for the following versions of SynapseBoard:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

We take the security of **SynapseBoard** seriously. If you discover a security vulnerability, please do **NOT** open a public GitHub issue.

Instead, please report vulnerabilities privately by following these steps:

1. Send an email to `security@synapseboard.dev` with a detailed description of the vulnerability.
2. Include reproduction steps, sample payloads, or proof-of-concept code where applicable.
3. Our core security team will acknowledge receipt of your vulnerability report within 24–48 hours and work on a prompt resolution.

---

## Disclosure Policy

- We request that you give us a reasonable timeframe (typically 30 days) to address and patch vulnerabilities before public disclosure.
- Security updates and patches will be released as minor or patch releases on GitHub.
